# Examples

**File → New from Example…** opens the example gallery. Every example
opens as an unsaved copy — experiment freely, nothing overwrites the
original.

## Tutorials

- **Tutorial 1 — Hello polytess**: the flow from the Getting Started
  chapter (log, variables, formatted strings, folders).
- **Tutorial 2 — Loops & conditions**: read a CSV into a table, loop
  over the rows, branch on success/fail, collect results.
- **Tutorial 3 — Watch folder**: a Trigger flow that reacts whenever a
  file appears, processes it and archives it — the classic automation
  pattern.

Your own domain plugins can ship additional examples under `examples/`
(discovered automatically alongside the bundled tutorials).

Tip: combine an example with the **Flow Assistant** — attach one of
your own input files and ask it to adapt the example to your process.
